# 汕头市金山中学 · 3D 校园模型

依据真实地理数据构建的汕头市金山中学（广东省汕头市濠江区礐石海关顶 41 号）校园三维模型，可在浏览器中以**俯视**、**鸟瞰**、**第一人称自由漫游**三种方式浏览。

## 打开方式

- **直接双击 `index.html`**（推荐 Chrome / Edge / Firefox 新版），无需联网、无需安装。
- 或在本目录运行本地服务器后访问 <http://127.0.0.1:8765/>：

```bash
python serve.py
```

首次加载约需 5–15 秒（在浏览器中生成地形、地表纹理和约 2 万棵树）。集成显卡会自动使用「中」画质，可在顶栏切换。

## 模型内容

- **地形**：SRTM 1″ 高程（经 OpenTopoData 获取）；校园范围内额外平滑以去除建筑/树冠造成的表面高程偏差，建筑、球场、广场处整平为台地，台地间陡坡渲染为石砌护坡。北侧为汕头港海面，远处为对岸市区。
- **建筑**：156 栋建筑轮廓来自 OpenStreetMap，按层数挤出；屋顶颜色取自卫星影像采样。包括高一/高二/高三教学楼、实验楼、行政楼（七一楼）、图书馆（白色扇形曲面屋顶）、仲和堂、体艺馆（椭圆穹顶）、天象厅（银色穹顶）、食堂、学生宿舍、教工宿舍、金中西校区等。
- **运动设施**：大操场（环形跑道 + 足球场 + 弯道区篮球场，尺寸按 OSM 轮廓拟合）、篮球场、排球场及篮架、球门。
- **道路与景观**：校内道路、人行道、台阶（3D 踏步）、景观天桥（可走上去）、七一广场、守素亭、日晷、扬帆、日月晖、梦之谷、观海平台、谷底溪流等。
- **植被**：依据卫星影像自动分类出的植被分布种植乔木、棕榈、松树和灌木；山坡裸露亮斑处放置礐石花岗岩巨石。

## 准确性说明

- 建筑层数除 OSM 已标注者（高一 7 层、高二 6 层、C 栋宿舍 6 层）外，均为依据卫星影像的估计。
- 校门位置依据门卫室与校内车道起点推断，**造型为示意**；亭子、雕塑、景石等小品的位置来自 OSM，造型为示意。
- 对岸汕头市区天际线与港湾船只为程序生成的氛围元素，非真实建筑。
- 如需调整层数、风格或介绍文字，编辑 `data/campus-info.js` 后刷新页面即可。

## 数据来源

- 建筑、道路、水体、运动场等：© OpenStreetMap 贡献者，ODbL 许可
- 高程：NASA SRTM 1 arc-second（经 OpenTopoData）
- 植被分布与屋顶颜色：由 Esri World Imagery 卫星影像自动分类/采样得到（仅保存分类结果与平均色，不含影像本身）
- 学校简介：汕头市金山中学官网、维基百科

本模型仅供学习交流，与实际情况可能存在差异。
